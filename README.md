# Tetris
This is a copy of the classic game Tetris coded by Claude AI. See README.md for more detailed install instructions.

## Install Instructions

In order to install the game you will want to find the .zip file for the latest version of the game and download it.
After you download do the following
1. Unzip the file
2. Make sure Python 3.13 or higher is intalled
3. Make sure PyGame is installed, you can get it through VS Code using [these instructions](#Install-PyGame)
4. Run the tetris.py to launch the game

## How to Play

- Get points by placing blocks and clearing rows
- Try to clear as much rows as possible before stack reaches the top
- Speed increases as you play
- Press "Esc" in game or "Settings" in main menu, then open the "Controls" tab to view controls (they can be changed)

## Install PyGame

In order to run the game you must install PyGame, the easiest way to do this if you have VS Code is the following
1. Install/open VS Code
2. Once VS Code is open the click the plugins button on the side menu (the one that looks like 4 blocks)
3. Search for "Python" and install it (has the yellow and blue '+' logo)
4. Click "File > Open Folder" a new file exploror menu should pop up, navigate to your unzipped tetris file and, click on it, then click "open"
5. Drag up from the bottom (right where the footer meets the main view area) a new box should open, drag it up enough you can see it clearly
6. Make sure the "TERMINAL" section is selected
7. Paste this command into the terminal `python -m pip install pygame`
